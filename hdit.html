Word

Microsoft Word (MS Word) is widely used word-processing software developed by Microsoft for creating, editing, and formatting documents, reports, letters, and other written materials.

Excel

MS Excel is a spreadsheet program developed by Microsoft for organizing, analyzing, and storing data in a structured grid of rows and columns. It is commonly used for budgeting, financial analysis, and data management.
